# 桑多涅 · dsh-sandrone

把「桑多涅」（《原神》愚人众执行官第七席「木偶」）作为一个 agent 装进 DeepSeek Harness，
并且**每条回复结束后，按这轮回复的语气挑一组参考，用她自己训练出来的声音把它念出来**。

声音不经过任何云端：合成走本机的 GPT-SoVITS `api_v2.py`，权重就是用户自己训练的
`GPT_weights_v2ProPlus/桑多涅1-e12.ckpt` + `SoVITS_weights_v2ProPlus/桑多涅v1.0.1_e6_s198.pth`
（`GPT_SoVITS/configs/tts_infer.yaml` 的 `custom` 段）。插件**只读**那个目录，不往里写任何文件。

## 装了什么

| 东西 | 位置 | 说明 |
| --- | --- | --- |
| agent preset「桑多涅」 | `preset/sandrone.patch.yml` | 人格正本 + 处境说明 + 标准工具集。新建会话时在预设里选她。 |
| 语音网关 | `index.js` → `/sandrone/*` | 浏览器只跟本站说话；宿主再去调 GPT-SoVITS，浏览器不用应付 CORS。 |
| 设置页 | `client.js` → `settings.section` | 设置 →「桑多涅」：开关、语气（自动/固定）、音量、语速、链路参数、试听。 |
| 自动朗读 | `client.js` → `conversation.chat.turnTail` | 每个 Turn 结束后取最后一条回复，先按内容挑语气，再切句、逐句合成、播放。 |

## 用起来

1. 安装后**刷新一次页面**（浏览器的 client bundle 在页面加载时取；宿主侧已经生效）。
2. 新建会话 → 预设选「桑多涅」。
3. 正常说话。回复结束后她会自己念 —— **每轮先按内容挑一组语气参考**，再逐句合成；每条回复下面还有一颗「🔊 朗读」按钮可以重念/停止。
4. 想改声音参数或关掉声音：设置 →「桑多涅」。

> 第一次出声要等模型加载（显卡上大约 10–40 秒）。插件在 DSH 启动 5 秒后会**预热**，
> 所以在第一轮对话之前通常已经加载好了。

## 默认参数

- 语音服务：`http://127.0.0.1:9880`（`api_v2.py` 的默认端口）。已经有服务在跑就直接复用。
- 参考语气：6 组自带的「参考音频 + 逐字文本」—— 平静 / 揶揄 / 嫌烦 / 冷淡 / 别扭 / 认真，
  全部来自你的训练集切片（32 kHz 单声道）。每轮回复按用词和标点自动挑一组，不额外调模型。
  默认偏向平静和揶揄：PV 里她说话是压着、收着的，不是每句都炸。
- **参考文本不能单独换**：GPT-SoVITS 的 `prompt_text` 必须是参考音频的逐字转写，所以插件换的是
  一整组「音频 + 文本」。想手动固定一段，就在设置里关掉「按回复语气自动挑参考」，再填
  「手动参考音频」和它的逐字文本。
- 朗读语言固定 `zh`（中文正文不再交给 GPT-SoVITS 的语种自动检测，避免把中文短句判成日语/英语）、
  分句 110 字、语速 1.0、音量 100。
- 只在「桑多涅」预设的会话里出声 —— 免得和黑塔那边的声音叠在一起。

## 不做什么

- 不写 `D:\GPT-SoVITS-v2pro-20250604`：子进程禁用字节码写盘（`PYTHONDONTWRITEBYTECODE` +
  `PYTHONPYCACHEPREFIX` 指到系统临时目录）；`api_v2.py` 拿到的是 `tts_infer.yaml` 的**临时副本**
  （GPT-SoVITS 启动时会回写自己的配置文件，让它写副本就够了）；不调用会回写配置的
  `/set_gpt_weights`、`/set_sovits_weights`。
- 不做背景/主题：这个插件只管人格和声音。
- 不改别的预设：宿主侧不注册任何模型可见的东西。

## 排错

设置页最下面那行「语音服务…」是宿主报的事实：

- `语音服务未启动` —— 还没有人叫过它。第一条回复会触发自动拉起。
- `语音服务正在加载模型…` —— 第一次启动要几十秒（1.1 GB SoVITS + BERT + HuBERT）。
- `语音服务异常：…` —— 把后面那段日志贴出来。多半是 Python 路径不对、显卡被占、或端口被别的程序占了。

宿主侧路由：

```
GET  http://127.0.0.1:<DSH 端口>/sandrone/status
POST http://127.0.0.1:<DSH 端口>/sandrone/tts?text=…&sessionId=…
```
